## ⚠️ One Thing You Need to Do

**Add Firebase Web Client ID:**
1. Open: `android/app/src/main/res/values/strings.xml`
2. Find: `default_web_client_id`
3. Replace `YOUR_WEB_CLIENT_ID_HERE` with your actual Firebase Web Client ID
   - Get it from: https://console.firebase.google.com/project/gen-lang-client-0114974661/settings/general
   - Look under "Your apps" → Web app → OAuth client ID
